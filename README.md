# manual-cafe-casa

Manual de barista em uma página (`index.html`) para o setup de casa:

- **Cafeteira:** Gaggia Classic E24 — caldeira única de latão, portafiltro 58mm, OPV ~9 bar, válvula solenoide de 3 vias, sem PID (temperature surfing) e pré-infusão manual pela manopla de vapor.
- **Moedor:** HiBREW G7 — 48 posições, dosagem por tempo, suporte de portafiltro configurado em 58mm.

Inclui timers, receitas (dose padrão 18g), checklist diário, calibração, pré-infusão, rotinas de limpeza (backflush e descalcificação) e teoria do café.
