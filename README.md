# manual-cafe-casa

Manual de barista em uma página (`index.html`) para o setup de casa:

- **Cafeteira:** HiBREW H21 — portafiltro 58mm, PID (88–96°C), pré-infusão programável, manômetro, vapor independente e válvula solenoide de 3 vias.
- **Moedor:** HiBREW G7 — 48 posições, dosagem por tempo, suporte de portafiltro configurado em 58mm.

Inclui timers, receitas, checklist diário, calibração, rotinas de limpeza (backflush e descalcificação) e teoria do café.
